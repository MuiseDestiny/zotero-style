## Installation & updates

1. [Download the plugin](https://gitee.com/MuiseDestiny/plugins/raw/master/zotero-style.xpi) and save the `.xpi` file.
2. In Zotero, open Tools → Plugins, click the gear icon in the upper-right corner, and choose Install Plugin From File. Select the downloaded file.

After installation, **check for updates** in the upper-right corner of Zotero Settings → Style.
