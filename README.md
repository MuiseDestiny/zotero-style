Ethereal Style 是一款面向 Zotero 的文献管理与阅读增强插件，帮助你更直观地查看阅读进度、组织文献与标签，并改善 PDF 阅读和工作区体验。

## 使用文档

使用方法见[文档](https://plugins.muisedestiny.xyz/docs/style)，其中 **Pro 功能**需[购买](https://plugins.muisedestiny.xyz/)并[激活](https://plugins.muisedestiny.xyz/guide)。

## 安装与更新

1. [下载插件](https://gitee.com/MuiseDestiny/plugins/raw/master/zotero-style.xpi)，保存 `.xpi` 文件。
2. 打开 Zotero「工具 → 插件」，点击右上角齿轮，选择「从文件安装插件」，选中下载的文件。

安装后，在 Zotero「设置 → Style」右上角可**检查更新**。
