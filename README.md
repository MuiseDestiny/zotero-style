Ethereal Style 是一款面向 Zotero 的文献管理与阅读增强插件，帮助你更直观地查看阅读进度、组织文献与标签，并改善 PDF 阅读和工作区体验。

**[阅读完整功能介绍与使用文档](https://plugins.muisedestiny.xyz/docs/style)**

README 仅提供功能概览。安装、配置、使用方法以及最新的功能说明，请以完整文档为准。

## 主要功能

- **阅读进度可视化**：记录 PDF 各页的阅读时长，在标题背景中呈现阅读热度，配合进度列查看标注分布。
- **条目列表增强**：提供期刊标签、影响因子、标签、#标签、状态、评级、简记等列，并支持列设置与视图组切换。期刊数据相关功能需要配置 easyScholar 等外部服务。
- **标签与分类管理**：支持嵌套标签、快捷打标签，以及分类排序、置顶和条目数显示。
- **PDF 阅读增强**：自定义 PDF 样式与标注颜色，合并跨页标注，快速切换附件版本。
- **翻译与词汇积累**：提供选句翻译、生词本和术语库等阅读辅助工具；选句翻译需要安装 Translate for Zotero。
- **工作区与文献关联**：通过关系图谱浏览关联条目，配合侧边栏快捷操作、菜单管理和自定义样式，整理自己的工作区。

## Pro 功能

**[加入 Pro](https://plugins.muisedestiny.xyz/)**

插件同时提供 **Ethereal Style Pro** 扩展能力，例如：

- **标签页管理**：垂直标签页、标签组与标签页管理器，便于在多篇文献之间切换。
- **探索与预览**：在侧边栏集中浏览文献内容，直接预览 PDF 附件或网页快照。
- **笔记与标注管理**：集中查看笔记和标注，通过反向链接回到引用位置，并使用文献矩阵比较多篇文献。
- **被引次数列**：在条目列表查看文献被引次数。

Pro 的完整功能、使用条件与激活说明，请查看 [Ethereal Style 文档](https://plugins.muisedestiny.xyz/docs/style)。具体功能范围以文档和当前版本的插件设置为准。

## 开源与代码说明

- **Pro 功能部分不开源**，其受保护实现以独立加密模块随插件分发。
- **非 Pro 功能代码未加密**，后续会逐步整理并同步到本仓库。
- 仓库源码与插件发布版本可能存在时间差；本仓库不代表插件的全部功能均已开源。
- 仓库中已公开代码的许可条款见 [LICENSE](LICENSE)。
